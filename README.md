# Bidmate

소규모 사업자를 위한 나라장터 용역 입찰 추천 MVP입니다. 회사의 지역, 주력 업종, 관심 키워드와 수행 가능 금액을 바탕으로 공고별 추천 점수와 이유를 보여줍니다.

## 실행

별도 패키지 설치 없이 Python 3.9 이상에서 실행됩니다.

```powershell
python app.py
```

브라우저에서 `http://127.0.0.1:8787`을 여세요.

## 주요 기능

- 회사 조건 기반 공고 추천 점수와 추천 이유
- 공고명·기관·키워드 검색, 분야 필터, 추천·마감·금액순 정렬
- 관심 공고 저장 및 별도 모아보기
- 마감 임박 표시와 준비 서류 체크리스트
- 반응형 대시보드와 로딩·오류 상태
- SQLite 영구 저장
- 공공데이터포털 나라장터 용역 공고 동기화

`.env`에 `DATA_GO_KR_SERVICE_KEY`를 설정하면 상단의 **실시간 공고 동기화** 버튼으로 최신 공고를 가져옵니다. 키가 없으면 제품 검증용 데모 데이터가 사용됩니다.

> 추천 및 자격 정보는 검토를 돕기 위한 참고 정보입니다. 실제 참여 전 나라장터 원문과 첨부 문서를 반드시 확인하세요.

## 공개 배포

이 저장소에는 Render Blueprint 설정이 포함되어 있습니다. Render에서 저장소를 연결하고 `DATA_GO_KR_SERVICE_KEY` 환경 변수만 등록하면 공개 웹 서비스로 실행할 수 있습니다.

무료 인스턴스의 SQLite 파일은 재배포 시 초기화될 수 있으므로, 운영 서비스에서는 영구 디스크 또는 PostgreSQL 사용을 권장합니다.
